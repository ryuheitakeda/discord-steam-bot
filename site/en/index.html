Features

What it does

No complicated setup. Link your Steam profile once, then just run a command in voice chat.

🔗

Link with /link

Paste your Steam profile URL, SteamID64, or custom URL name — that's it, no external login flow. Unlink anytime with /unlink, or check your status with /profile.

🎮

/games suggests shared titles

Pulls the games shared by every linked member currently in your voice channel, filters for multiplayer-ready titles, and lists up to 10 sorted by recent playtime. Add all:True to see the full unfiltered list.

🎲

/pick for a single suggestion

Too many options? /pick randomly selects one title from your shared library — for when you don't even have time to discuss.

👥

Automatic voice channel detection

No need to specify a channel. The bot detects the voice channel the command author is currently in, and runs as soon as two or more linked members are present.

How it works

Three steps to get started

1

Add to Discord

Add the bot to your server using the button below. That's the whole setup.

2

Run /link

Each member links their Steam profile URL with /link. Make sure "game details" is set to public in your Steam privacy settings.

3

Run /games in your VC

Once everyone's in the voice channel, run /games (or /pick). Suggestions arrive instantly.

FAQ

Frequently asked questions

What languages are supported?
Japanese and English. Replies automatically match your Discord client's display language.
Does it work if my Steam profile is private?
/games and /pick need "game details" set to public in your Steam privacy settings to read your library. Members without public game details are excluded from the results and listed in a footer note.
How many people need to be in the VC?
At least two linked members with a readable game library need to be present in the voice channel. It won't run with only one member, or if nobody has linked their account.
What happens when the free limit is reached?
Each server gets up to 3 uses per day and 60 per month (combined for /games and /pick). Both limits refill automatically as time passes on a rolling window. Upgrading to Premium removes the limit immediately.
How does billing and cancellation work?
Premium is billed via Stripe by credit card. Check your subscription status anytime with /premium, and cancel from there as well.
How is "multiplayer-ready" determined?
The bot checks each title against Steam Store data and caches the result. This check takes a little time, so right after adding the bot, a few titles may not yet appear in the results — they'll show up the next time you run the command.
